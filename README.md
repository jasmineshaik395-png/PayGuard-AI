# PayGuard AI

PayGuard AI is a beginner-friendly payment risk analysis prototype.

## Features
- Analyzes fictional transactions.
- Assigns demo risk scores using simple rules.
- Displays a risk chart and transaction details.
- Allows users to check example transactions.

## Technologies
Python, Streamlit, Pandas, Plotly.

## Run the project
Install dependencies with `python -m pip install -r requirements.txt`.
Run with `python -m streamlit run app.py`.
Open http://localhost:8501 in your browser.

## Limitations
This educational prototype is not connected to PayPal or a bank and does not yet integrate the PayPal Developer Sandbox or an external AI model. The rules are not validated for real fraud detection.
